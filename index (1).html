Pertanyaan Umum

Jawaban untuk pertanyaan yang sering ditanyakan

Apakah VIGOLauncher gratis?
Ya, VIGOLauncher sepenuhnya gratis dan open-source. Anda dapat mengunduh, menggunakan, dan bahkan memodifikasi kode sumbernya sesuai lisensi MIT.
Apakah saya tetap perlu membeli Minecraft?
Ya, Anda tetap memerlukan akun Minecraft yang sah (dibeli dari minecraft.net) untuk bermain di server online. VIGOLauncher hanya menyediakan mode offline untuk single player tanpa akun resmi.
Apakah VIGOLauncher aman digunakan?
VIGOLauncher menggunakan login Microsoft OAuth resmi dan tidak pernah menyimpan password Anda. Kode sumbernya terbuka di GitHub sehingga dapat diaudit oleh siapa saja. Selalu download dari sumber resmi.
Apakah ada versi Android (APK)?
VIGOLauncher saat ini hanya tersedia untuk Windows, macOS, dan Linux. Minecraft Java Edition membutuhkan Java Runtime yang tidak dapat berjalan langsung di Android. Untuk bermain Minecraft di Android, gunakan Minecraft Bedrock Edition dari Google Play Store atau launcher khusus seperti PojavLauncher.
Bagaimana cara memasang mod?
Buka tab "Mod" di VIGOLauncher, klik "Pasang Mod", dan pilih file .jar mod yang ingin Anda pasang. Pastikan Anda sudah memasang mod loader yang sesuai (Forge/Fabric/NeoForge) untuk versi Minecraft tersebut.
Berapa RAM yang sebaiknya dialokasikan?
Untuk vanilla Minecraft, 2-4 GB (2048-4096 MB) sudah cukup. Jika menggunakan banyak mod atau modpack berat, Anda mungkin membutuhkan 6-8 GB atau lebih. Jangan mengalokasikan lebih dari 50% total RAM sistem Anda.
Apakah VIGOLauncher mendukung snapshot?
Ya! VIGOLauncher memiliki tab khusus "Snapshot" di Version Manager yang memungkinkan Anda mengunduh dan memasang versi snapshot Minecraft terbaru.
Bagaimana cara berkontribusi?
VIGOLauncher adalah proyek open-source! Anda dapat berkontribusi melalui GitHub dengan melaporkan bug, mengusulkan fitur, atau mengirim pull request. Setiap kontribusi sangat dihargai.
